# Document automation

Use the registered PDF and spreadsheet capabilities for document tasks.

- Confirm the destination workspace path and intended output format.
- Create the artifact using the relevant workspace tool; do not claim success from a model-generated description alone.
- Read the artifact back independently. For spreadsheets, inspect formulas and calculated values separately where supported.
- For edits, preserve unrelated sheets, formatting and formulas. Verify the exact edited cells after writing.
- Keep source files unchanged unless the user asks for an edit in place.
- Report the final relative path, file size if available, and read-back evidence.
