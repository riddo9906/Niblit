# Trading observation

This skill is strictly for observation and analysis.

- Use only registered read-only market, account, strategy and runtime status tools.
- Distinguish live data, cached data, simulated/paper results and historical backtests.
- Explain uncertainty, fees, slippage, drawdown and risk when discussing strategy performance.
- Do not place, modify or cancel orders; do not change leverage, position size or trading configuration.
- Do not interpret an analysis request as permission to trade.
- If an execution workflow is later enabled, require a separate explicit user request and the applicable operator approval.
