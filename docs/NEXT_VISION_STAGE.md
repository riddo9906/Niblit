# Next stage: Niblit's eyes

User direction, 29 October 2026: after confirming the trading system can place
and manage trades, build a vision system for a home CCTV installation.

Planned scope:
- Camera feed adapters with source identity, health, timestamps and reconnect handling.
- Object recognition, activity/pattern recognition and event detection.
- Facial recognition for people deliberately enrolled, keeping uncertain matches
  distinct from confirmed identity. Unknown people remain unknown.
  Unknown passersby will not be identified by matching CCTV faces against social
  media profiles or external identity databases. Intrusion events and incident
  evidence can be recorded without assigning identities to unknown visitors.
- A memory category system linking keywords and labels to objects, events and
  locations, with confidence, source camera, time and supporting frame/clip references.
- Search and inspect evidence before promoting observations into lasting knowledge.
- Link to the existing memory framework without mixing facial templates, trading
  vectors and general language embeddings in the same collection.

No camera connection or recording is configured by this note. Camera hardware,
feed protocols, local processing capacity, retention and enrolled identities will
be established when the vision stage begins. Trading verification remains the
current implementation task.
