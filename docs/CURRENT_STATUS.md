# Current status and documentation map

Updated 29 October 2026. Niblit is an actively developed AI runtime and programmer
workspace, maintained by Enginehead Software Development. The broader AIOS vision
is a roadmap, not a claim that it replaces a desktop operating system today.

## Capability evidence and limits

| Area | Demonstrated / implemented | Still required |
|---|---|---|
| Desktop runtime | Integrated Core, UI, Cloud and Lean in tested Windows builds | Reproducible fresh-machine installer and release provenance |
| Local inference and tools | Earlier source-file question/follow-up through real Qwen and governed workspace reads | Repeat critical flows against the exact distributed build |
| Memory | Persistent legacy knowledge, conversation history, governed evidence ledger and Qdrant projection | Complete adapter coverage, relevance/quality controls and lifecycle acceptance |
| PDFs | Bounded workspace text extraction with page references | Full current attachment-to-model validation; scanned PDFs require OCR |
| Trading | Observed MT5 demo fill; Freqtrade dry-run integration and manual review controls | End-to-end close acceptance, strategy evaluation and full outcome feedback |
| Autonomy | Research/learning modules and managed jobs exist | Truthful unified status, bounded domain evaluations and sustained recovery tests |
| Hosted clients | Local shared/private portal prototype, approved sign-up, roles and pilot tier tests | Cloud deployment, real inference round trip, operational review and billing |
| OS/vision | Existing design and partial adapters | Governed implementation and acceptance; no general autonomous desktop capability claim |

These rows describe development evidence, not a promise that every local change is
in the public default branch or every packaged release. Tests with scripted
responders are distinct from actual model inference. A working connection or demo
order does not demonstrate financial performance or a funded trading service.

## Configuration boundaries

Choose the intended profile before starting it. Old cloud examples may enable
autonomous loops, optional providers and trading-related subsystems. Do not treat
them as a secure client-portal deployment. Keep secrets in private environment
configuration and preserve personal memory separately from source control.

Paid inference is optional and incurs provider costs. Stored feedback is not
automatic model-weight training. Local inference still requires compatible model
files, a functioning inference runtime and sufficient hardware.

## Release acceptance

A complete release needs a source/dependency manifest, documented configuration,
fresh-target install, startup health, a real UI-to-backend response, persistence
across restart and recovery checks. No clean-install-tested bootstrap download is
claimed until those checks pass. Funded trading and revenue targets remain unproven.
